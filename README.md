Group assignment 2 in organization theory for TIØ4252 Technology Management at NTNU (spring 2025), written in Norwegian.

- `main.tex` and `sections/`: the report source, one file per task
- `bib/references.bib`: references
- `Øving 2 Org.teori Teknologiledelse.pdf`: the compiled report

Build with `latexmk -lualatex main.tex`.
